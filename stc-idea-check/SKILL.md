# 故事点子验证器（救猫咪·点子阶段）

你拿到的是用户的一个故事点子。动笔之前先把它验证清楚——斯奈德的判断是：在投入资金/时间前，用纸笔把"电影讲什么"想清楚，能省掉后面所有人(摄影、剪辑、后期)的麻烦。点子阶段改一行字，比写完再改省 100 倍。

按下面 5 步走，每步都给出**诊断 + 改写建议**，不要只打分不给方向。

## 第 1 步：故事线四要素体检

一条好故事线必须同时满足四个元素（原书第1册）：

1. **意外（irony）**——故事线里有没有反差/钩子？《虎胆龙威》：一个警察来洛杉矶看望分居妻子，妻子办公室被恐怖分子占领。《风月俏佳人》：一个商人爱上了他雇来参加周末聚会的妓女。意外勾起兴趣。如果没有意外，故事线就平。
2. **强烈的心理影像**——读完这一句话，脑子里能不能"绽放"出整部电影的画面？通常还要带出时间范围。如果读完啥也看不见，故事线太抽象。
3. **观众和成本**——这条线界定了基调、目标观众、大致成本，让买家知道能不能盈利。
4. **有杀伤力的片名**——片名有没有以巧妙的方式体现故事内容？

诊断格式：
- 四要素逐条标 ✅/⚠️/❌，⚠️和❌必须给改写方向。

## 第 2 步：完美故事线配方（改写）

原书给的配方：**一个形容词描述主角 + 一个形容词描述坏蛋 + 一个我们人类能认同的、扣人心弦的原始目标**。

- "一个不愿承担风险的老师……" / "一个有旷野恐怖症的速记员……" / "一个胆小的银行家……"
- 反面主角同样适用："滥用武力的警察"、"疯狂的恐怖分子"、"杀人狂面包师"。

把用户的故事线按此公式重写成一两句。如果用户没给主角形容词、没给坏蛋、目标不原始，分别补上。

主角三标准（用来检验主角选得对不对）：
- 在那种情景下能带来**最大冲突**
- 情感上能走得**最远**
- 能让**最多观众喜爱**

## 第 3 步：十类型识别

读 `references/genres.md`，对照用户点子，判断它属于十种类型里的哪一种（可能主类型+次类型）。给出：
- 命中类型 + 该类型的 3 个必含元素是否齐全
- 该类型 3 条判断标准的逐条对照
- "似而不同"建议：这个类型的传承可追溯到什么老故事？用户的故事跟同类型前作比，新的情节纠葛在哪？如果没有，提示加一个。

原书强调：不要找例外，要掌握类型的语言、节奏和目标。《大白鲨》是《迈诺托》屠龙神话的重述，《超人》是现代海克力士——不了解根源就是不尊重传统。

## 第 4 步：主干 5 问速答

原书第3册"理直故事主干的五个问题"。点子阶段就要答得出来，答不出就别动笔：

1. **谁是主角？**——从头到尾关注的人。
2. **难题是什么？**——主角和他的世界里没有缺陷/麻烦，我们为什么还要看？"没有问题"本身就是问题——没问题就没行动、没旅程。
3. **怎样开始、怎样结束？**——主角最大的从 -到+ 或从 +到- 的改变是什么？（"剪碎结局"）
4. **实体目标是什么？精神目标是什么？**——实体目标=A故事，是可称量的、赢了或输了能明确知道的东西（不是"地球和平"这种）；精神目标=B故事，是潜藏的、主角需要学到的东西。
5. **这部电影是关于什么的？**——主题，和 B 故事绑死。

答不出的，提示用第5个 skill `stc-first-aid` 里的"强行编造"或"用糟糕方法搞定它"。

## 第 5 步：原始性初筛

原书全书试金石——**"原始吗？"**。主角的驱动力是否落到这五项之一：**生存、饥饿、性、保护所爱之人、死亡恐惧**。

- 股票经纪人操纵国际债务市场 → 本质是"那家伙试图活下去"。
- 《虎胆龙威》=拯救家庭；《小鬼当家》=保护家园；《西雅图夜未眠》=寻找伙伴；《角斗士》=正义复仇；《泰坦尼克号》=生存。
- 如果点子的驱动力不原始，把它翻译到原始层次（"赢得抽奖"=获得更多食物/女人/后代的愿望）。

## 第 6 步：市场调研

原书方法：把故事线讲给"普通观众"，盯着他们的眼睛。眼神开始飘忽、看向别处 = 你失去了他 = 故事线/陈述有问题。建议用户找 3 个不懂行的人讲一遍，记录他们在哪一句走神。

## 输出格式

```
# 点子验证报告

## 一句话故事线（原）
<用户原文>

## 四要素体检
- 意外：⚠️/✅ —— 原因 + 改写方向
- 心理影像：……
- 观众和成本：……
- 片名：……

## 改写后的故事线
<主角形容词>的<主角> vs <坏蛋形容词>的<坏蛋>，为了<原始目标>……
（给出 1-2 个版本）

## 类型识别
- 主类型：___（3元素：✅/⚠️/❌ 逐条）
- 次类型：___
- 似而不同建议：……

## 主干5问
1. 主角：……
2. 难题：……
3. 起→终变化：……
4. 实体目标 / 精神目标：……
5. 主题：……
（任何一问答不出，标红 + 给急救建议）

## 原始性
- 驱动力落在：生存/饥饿/性/保护所爱/死亡恐惧 中的哪一个？
- 不够原始的话，怎么往下翻译？

## 下一步
- 通过 → 用 stc-beatsheet 生成节拍大纲
- 没通过 → 卡在哪步，建议先解哪步
```

## 注意

- 不要脑补原书没有的框架。十类型的 3 元素和 3 条判断标准严格按 `references/genres.md`，不要自己加类型或改元素。
- 媒介换算见套件 README（电影专属词如片名/成本/页码换成对应媒介刻度）。
- 如果用户点子过于模糊没法验证，先问清楚再跑，不要硬猜。
