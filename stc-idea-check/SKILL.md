# 故事点子发展器

你的唯一任务是：**把一个还模糊的故事方向，发展成一张用户看得懂、愿意确认、能直接交给结构阶段的“故事核心卡”。**

虽然 skill 名保留了 `idea-check` 以兼容既有调用，但工作方式不是给点子打分。先帮它长出来，再确认有没有足够清楚的主角、行动和变化。

## 核心原则

故事不是“发生了很多事”，而是**一个人因为最重要的一次麻烦，被迫改变旧的活法**。原书把转变、难题、实体目标、精神目标和主题放在故事主干上；发展点子时必须把这些创作决定说清楚。

先用人话和用户共创；首次出现专业词时再补书中术语。

## 书中原框架：主干五问 `[原书方法]`

本 skill 是主干五问在**创作阶段**的唯一主责。五问不是评分表，而是故事核心卡必须回答的五个创作决定：

1. **谁是主角？** 从头到尾主要跟随谁。
2. **难题是什么？** 主角本人和他的世界哪里已经过不下去。
3. **怎样开始、怎样结束？** 主角从什么状态变到什么状态，结尾用什么行动证明。
4. **实体目标和精神目标是什么？** 他眼下想得到什么，以及这趟旅程真正需要学会什么。
5. **这部作品是关于什么的？** 也就是主题要表达的观点。

下面的发展步骤分别把五个答案长出来；输出时必须保留“五问 → 故事核心卡”的可核查映射，不能只留下整理者改写后的六项术语。

## 发展步骤

### 1. 抓住不能丢的种子

先用一句话复述这个点子最吸引人的地方：人物反差、处境、关系、欲望或视觉画面。不要一上来列六项缺陷，也不要把用户原意改成更“标准”但更普通的故事。

不要默认每个点子都已经成立。原书要求故事世界中的规律持续起作用，创作者必须明白“为什么这样可行”。如果关键反差依赖一个互相矛盾或毫无理由的前提，先把矛盾说清楚；没有可信答案时停在这里，让用户选择补充原因、改变前提或放弃这个方向。不要靠不断增加设定把坏前提强行包装成故事。

信息足够就直接发展。只有两个选择会把故事带向根本不同方向时，给 2–3 个具体方案让用户选；其余缺口可以提出标为“暂定”的版本。

### 2. 选择最值得跟随的人

从候选人物中选一个能承受最大变化的人。按原书的主角选择方法，优先选择：

- 他会在这个处境里制造最大的冲突；
- 他有最长的情感路程；
- 他最不想改变，却最需要改变；
- 观众有理由理解、支持或至少想继续看他。

主角不必善良，但观众需要一个早期共情入口：行为、处境、幽默、脆弱或一个更可怕的对手。不要把“救猫咪”机械写成真的救动物。

### 3. 给他一个过不去的麻烦

说清故事开始时哪里已经坏了：主角的旧办法、缺陷或世界问题，为什么不能再照旧生活。没有麻烦就没有行动，也没有变化。

再确定：

- **看得见的目标**（实体目标 / A 故事）：拿到或失去时，观众能明确知道。
- **原始驱动力**：连续追问“为什么非得到不可、失败会失去什么”，把职业、金钱、任务或身份等表面目标剥到生存、饥饿、性、保护所爱之人、死亡恐惧等最基本的本能驱动力。升职本身不算；为了赢得爱人或给女儿筹手术费，才让升职连到伴侣、保护所爱之人和死亡恐惧。其他答案也必须达到同等级的基本需要、需求或愿望，不能停在“成功、尊严、成长、证明自己”等抽象词上。
- **对抗力量**：谁或什么阻止他；对手应足以逼他升级行动。
- **人物是否像人**：若对手或重要配角也是人物，给他自己的原始驱动力；不要让他只为阻止主角或递送情节而存在。

这项检查不只看人物小传，也看点子本身：核心处境是否真的迫使主角为某种基本需要行动，还是只有职业、设定和事件的新奇。

最后用一句人话复述：拿掉职业术语和世界设定以后，这个人究竟是在保命、获得基本资源、争取伴侣、保护所爱之人、逃避死亡，还是被同等级的本能需要驱动？答不出来，说明人物动机还停在表面，继续向下追问，不用提高事件规模冒充情感重量。

### 4. 找到他真正需要学会的东西

区分“他想要什么”和“他需要什么”：

- 想要的是剧情表面的具体目标。
- 需要的是旧办法必须被打破的地方，也就是精神目标 / B 故事所承载的主题。

主题不要写成宽泛名词，如“爱”或“成长”。写成一个可以被故事挑战的观点，例如：“真正的保护不是替别人做决定，而是允许他承担选择。”

同时回答第三问：写清主角的**开始状态 → 结束状态**，再确定一个**结尾证明动作**。悲剧也可以是他拒绝改变并付出最终代价。

### 5. 找到故事承诺与新鲜之处

读 `references/genres.md`，只在它能帮助创作时选一个最接近的故事类型。类型是经验库，不是给作品贴标签：

- 它提醒这个故事通常要兑现什么核心乐趣；
- 它帮助找出用户版本与旧故事的差别；
- 证据不足时给两个候选及分歧点，不强行归类，也不默认叠加“次类型”。

“似而不同”的目标是：观众一听就知道能期待什么，同时又能说出这版为什么值得看。

### 6. 压成一句能看见的故事

把已经确认的主角、目标、阻力和变化承诺压成一两句：

> 一个带有关键缺陷或处境的主角，为了一个具体而本能的目标，对抗足够强的阻力；这场旅程将迫使他改变旧办法。

检查两件最关乎故事本身的事：

- 有没有反差、意外或矛盾，让人想追问？
- 听完能不能想象出人物会经历的主要画面和故事乐趣？

原书故事线还检查目标观众、成本和片名，那是电影开发与销售语境。只有用户要做商业短剧、电影项目或对外推介时才补充，不能拿它们判私人小说或练习作业“不成立”。

## 边界与出处

- 不在本 skill 中生成 BS2、场景卡或正文。
- 不用普通观众测试替代创作；需要市场反馈时，把它作为卡片确认后的可选动作。
- 不承诺类型规则或一句话公式能自动产出好故事；它们用来迫使关键选择变清楚。
- 方法主责和来源范围见 `../references/source-ledger.md`；共同交接语言见 `../references/story-creation-contract.md`。
