# 创作急救箱（救猫咪·心法阶段）

这个 skill 不查故事，查的是**写故事的人**。原书作者布莱克·斯奈德自己就是"转变"故事的最佳样本——他从一个卖不出剧本的小卡拉咪，靠一套自我规训在一个夏天崛起。他反复说：**"撞墙""走投无路"不是终点，是乐趣开始的地方、是需要真正写作技巧的时候。**

按用户当下的卡点，选对应的急救法。不要一次全倒给用户——先听他卡在哪，再给对的那一剂。

## 急救 1：找不到"难题" / 没东西可写

**强行编造**（原书第3册）。把这个方法应用在任何写作困境中，它强迫你给出"改变"，而这种改变你原先可能认为并不需要。

- 觉得找不出"难题"所在，或根本没有任何想法？**编一个**。这是"强行编造"的乐趣，可行、有效。
- 配套口号：**"用糟糕方法搞定它"**。当找不到难题时，说一句"用糟糕方法搞定它"，然后说些傻乎乎的事。这会减轻压力——你会常常发现，这些表面上傻乎乎的事不仅不傻，而且正是解决方案。

为什么有效：难题不是凭空出现的，是逼出来的。原书："如果没有什么是不对的，为什么还要开始这段旅程？"——所以先硬塞一个不对的，旅程就开始了。

## 急救 2：找不到主题

原书第3册的真实案例：一个 40 人的动画师团队被困住——不知道结局、定不了中点、第三幕转不进去。反复推敲"一无所有""灵魂黑夜"都没用，直到问了一个本该早明确的问题："你的电影主题是关于什么的？"——他们有 5 个不同选择，所以没结局，因为没有主题就没指南针。

**写清单法**：拿一张白纸，坐下，写"关于我故事主题的 30 个糟糕点子"。一直写满 30 个。在这 30 个糟糕点子里，会有一个很棒的——那就是你需要的那个。

辅助提问：
- 这个主角学到了什么？
- 故事的寓意是什么？
- 你想借角色表达什么观点/关注点/思考维度？
- 如果片名就体现主题，这片名是什么？
- 你的电影最像哪部电影，从中能学到什么？

为什么有效：主题不是想出来的，是逼出来再筛出来的。30 个糟糕点子的清单法绕开了"直接想一个完美的"这种压力。

## 急救 3：撞墙 / 走投无路 / 怀疑自己

原书原话："撞墙""走投无路"只是个开始；这才是乐趣开始的地方以及需要真正的写作技巧的时候。如果你用这种心态坚持面对各种困境，就不会失败。

- **害怕也能激发创意**：把最好的点子从一个人头脑里挤出来的方法，往往就是把他逼到墙角、无路可退、必须面对问题。凌晨三点的冥思苦想，没准就让你找到剧情重点。
- **转变 = 死亡**：原书最终主题——"转变"中的一个部分就是"死亡"。当面对一堵砖墙（所爱之人死去、旧观念消亡），我们必须拥抱"新的"以求生存、兴旺。写作中的撞墙、无路可走对我们是好事，因为这让我们更加人性化；我们经历的任何"死亡"、任何失败都让我们更加人性化。所以**拥抱它，甚至寻求它，总要准备好超越它**。

## 急救 4：设定目标 / 找方向 / 没动力

这是作者自己崛起的方法，来自原书第3册最后一章。

**"规训 · 重点 · 正能量"**——三词真言，作者写在第二张索引卡上，紧闭的闸门就此打开。

1. **规训**：每天做一件让事业前进的事，不止写东西（即使第二天扔掉）。定页数目标、定截稿期。下午筋疲力尽时写信/打电话联系朋友。
2. **重点**：作者意识到自己没什么特别所长后，**自己给自己定一个**——"家庭喜剧"。放弃工作后放松看的类型，转而思考能提供什么服务。严格精确关注这个重点，拿掉所有不是重点的内容，终于清楚自己能给出什么好剧本/好服务。
3. **正能量**：不总是积极，但定下新生活规则——没做成某事不责备自己认定为失败，明白明天可以做得更好。被放鸽子一个半小时车程后爽朗乐观地告知经纪人，反而因这态度被邀午餐，午餐中安排了那年大部分工作。

**愿望卡 + 行动卡**（原书关键图景）：
- 作者墙上挂一整套目标（愿望卡），下面压着那张"规训 重点 正能量"索引卡（行动卡）。
- **如果只有一张"愿望卡"而没有那张"行动卡"，"愿望"就仅仅是"愿望"，没有实现的可能。**
- 你永远不知道这些"愿望"加"行动"将把你带往何处。

作者强调：在写下这些日记声明、宣告"我变了"之前，他**一个剧本都还没卖出**。但通过宣称我变了，他真的改变了；通过设定目标、时刻谨记、追求目标，目标真的开始实现——"证明"一一出现。

## 急救 5：我就是故事 / 关系即机会

原书："每桩剧本交易都有个故事。你就是故事。"

- 建立个人关系让目标人物认识你、了解你，是介绍作品的最佳方法。
- 介推优先级：见面 > 电话 > 书信 > Email（冷邮件最弱）。
- 作者卖不出剧本/没工作时做了一件令人惊叹的事：邀请经纪人吃午餐并**感谢她**——"谢谢你代理我，我知道你尽力了，我很难卖，这个市场本身就难，你是我和电影界沟通的桥梁，我非常感谢你。"——经纪人会为这样的委托人全力以赴。

## 输出格式

不要套固定模板。根据用户卡点：
1. 先复述用户卡在哪（确认听懂）。
2. 给对应的 1-2 剂急救法（不要 5 剂全倒）。
3. 给一个**当下能做的具体动作**——不是"保持乐观"，是"现在拿一张纸写下 30 个糟糕点子"或"现在编一个难题，哪怕很傻"。
4. 如果涉及目标设定，给出"愿望卡 + 行动卡"的具体填写建议（用户的愿望项 + 对应的每日规训动作）。

## 示例

**输入（用户的卡点）**："在写一个创业者的故事，写到中点卡住了，主角太顺利，不知道该让他遇到什么。"

**急救输出**：
1. **复述卡点**：你卡在中点，主角太顺利——他需要一次"虚假的胜利"之后立刻被砸下去。顺利 = 没威胁 = 没转变。
2. **给两剂急救**：
   - **强行编造**：现在编一个难题，哪怕很傻。"他刚签下大单（虚假胜利），转头发现合伙人在卷款跑路"——先让事情出错，不用管合不合理。
   - **用糟糕方法搞定它**：编不出来就说个更傻的——"外星人把他的服务器搬走了"——然后你会发现把它翻译成现实版（服务器被黑 / 被供应商断供）就有了。
3. **下一步动作**：拿张纸写下"能砸到他头的 3 件最糟的事"，选最原始的那个（危及生存 / 失去所爱 / 被信任的人背叛）。

## 注意

- 这个 skill 不是心理咨询，是创作心法。不要滑向励志空话——每条建议必须落在"下一步具体动作"。
- 全部内容来自原书第3册作者自述，不要脑补作者没说的方法。
- "转变/死亡"主题是原书终极论点，用在用户撞墙时点出，不要泛化成鸡汤。
- 用户如果不是创作卡点而是纯情绪低落，建议他先离开键盘做点别的，别硬套框架。
