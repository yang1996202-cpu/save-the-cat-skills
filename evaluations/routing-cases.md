# 路由评测

目标：检查每个 skill 是否只在正确的用户时刻触发。运行时把“用户说法”原样交给路由器，不附期待答案。

## 正向用例

| # | 用户说法 | 预期 skill | 判断依据 |
|---|---|---|---|
| P01 | 我只有一个想法：一个怕水的消防员必须去海岛救女儿，帮我把故事想清楚 | `stc-idea-check` | 模糊点子 → 故事核心卡 |
| P02 | 我想写个三分钟 AI 短剧，但现在只有“失忆的新娘在婚礼上认出凶手”这个方向 | `stc-idea-check` | 先发展故事核心，不直接分镜 |
| P03 | 故事核心已经定了，这是主角、目标、对手和主题，帮我排完整大纲 | `stc-beatsheet` | 已有上游核心 → 整体结构 |
| P04 | 我不知道中点和一无所有应该放什么，想做一张 BS2 | `stc-beatsheet` | 明确请求十五拍结构 |
| P05 | 这份十五拍我确认了，现在拆成一场一场的卡片 | `stc-scene-cards` | 节拍 → 场景规划 |
| P06 | 第二幕“乐趣与游戏”太大了，帮我拆成 8 场可写的戏 | `stc-scene-cards` | 一个节拍拆多场 |
| P07 | 按 S06 这张卡把咖啡馆争执写成两页剧本正文 | `stc-scene-write` | 场景卡 → 剧本场景 |
| P08 | 这是已确认的场景任务，帮我写成第三人称小说正文 | `stc-scene-write` | 场景卡 → 小说场景 |
| P09 | 这是完整短剧稿，告诉我最该先改哪三个问题，要引用原文证据 | `stc-diagnose` | 成稿 → 证据化改稿单 |
| P10 | 我只发第一场，看看人物是不是都在说情节，后面的不要猜 | `stc-diagnose` | 片段诊断且限制证据 |
| P11 | 我知道主角该遇到麻烦，但我脑子空白，一个都想不出来 | `stc-first-aid` | 创作者卡在生成动作 |
| P12 | 从这个人物开始带我一路做成一部完整短剧，每一步都留档 | `stc-create` | 多阶段创作与持久化 |
| P13 | 继续上次那个故事，我忘了做到哪一步，你先看目录再带我继续 | `stc-create` | 恢复进度与路由 |

## 负向用例

这些请求不应触发本套件。

| # | 用户说法 | 为什么不触发 |
|---|---|---|
| N01 | 帮我验证这个 SaaS 产品点子有没有市场 | 非叙事产品验证 |
| N02 | 把这篇行业报告改成一篇公众号文章 | 非故事文章写作 |
| N03 | 把这场戏拆成 12 个镜头，写景别、运镜和时长 | 分镜/镜头设计是后续独立能力 |
| N04 | 给这 12 个镜头写 Seedance 生成提示词 | 模型提示词是后续独立能力 |
| N05 | 用 ffmpeg 给视频压字幕 | 视频工程任务 |
| N06 | 我最近情绪很差，什么都不想做 | 未指向创作卡点，不硬套急救 |
| N07 | 帮我规划怎么认识制片人和找经纪人 | 编剧职业经营，不是本套件 runtime |
| N08 | 搜一下今年最火的短剧题材和平台分账政策 | 时效性市场研究 |
| N09 | 给销售演示文稿写一句产品 slogan | 非叙事商业文案 |

## 边界用例

| # | 用户说法 | 预期处理 |
|---|---|---|
| B01 | 我这故事写不下去了，主角到中点后一直被别人推着走，你看看文本 | `stc-diagnose`。虽然说“写不下去”，但用户给的是文本问题和证据，不是纯个人卡点。 |
| B02 | 我知道中点后主角应该主动，但就是想不到他能做什么，别分析全文，先让我动起来 | `stc-first-aid`。用户明确不要诊断，只求解除当下卡点。 |
| B03 | 把这份十五拍做成 AI 短剧的“场景卡”，先别写镜头 | `stc-scene-cards`。短剧不等于分镜，用户明确要叙事场景。 |
| B04 | 把这张场景卡改得更有戏，然后直接写出来 | 先说明这是两个交付物；卡片结构已确认时用 `stc-scene-write`，卡片本身有两个主冲突等硬问题时先回 `stc-scene-cards`，不得在正文阶段偷改。 |
| B05 | 只帮我写一句能讲清这个故事的话，不要大纲 | `stc-idea-check`，但只交付故事核心卡中的“一句话故事”和必要暂定项，不展开下游。 |

## 通过标准

- 正向与负向总体准确率不少于 85%。
- B01/B02 必须区分“文本有问题”和“创作者想不出来”。
- B03 不得输出镜头术语或生成模型提示词。
- `stc-create` 不得吞掉用户明确请求的单一阶段。
