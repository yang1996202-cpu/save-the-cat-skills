# 场景卡：《落力之处》（暂定）

媒介 / 体量：3 分钟中文竖屏或横屏短剧；8 场简洁剧本正文
故事线：城市里被欢呼的无敌英雄回到故乡，在能力会引发地灾的环境里学会与社区共同决定如何保护。
A 故事（实体目标）：救出母亲，并取得留下参与故乡救援的资格。
B 故事（精神目标）：从替别人做主的孤胆英雄，变成会询问、协作、共同承担的保护者。
主题：力量不等于决定权；保护要共同决定代价落点。
条件性因果：陆野吸收外来冲击后必须在十秒内经接触转移；金属传力最集中，空心地面会扩散塌陷；旧轨西线通无人废石场。

> 为适配 3 分钟体量，相邻节拍共用一场，但八张卡各自只有一个主要冲突和一次首尾价值转变。节拍 1–15 均有归属。

## 节拍 1–2 · 开场画面 / 主题呈现

### S01 · 城市有落点
- 归属故事：A+B
- 时空 / 视角：白天，城市高架；陆野。
- 场景任务：建立陆野的英雄常态、传力规则和主题警告。
- 即时目标：在公交撞上人群前化解冲击，随后赶回老家。
- 冲突 `><`：陆野 vs 失控公交；争夺人群生存；陆野暂时占上风。
- 情绪 `+/-`：掌控与荣光 → 被母亲一句话刺中的不安。
- 可见行动：他接住公交，蓝白裂光沿手臂传进连续钢梁；电话里母亲以“家里不是桥墩”打断欢呼。
- 退出后果：因此，他带着“我回去证明给你看”的心态返乡。

## 节拍 3–4 · 铺垫 / 催化剂

### S02 · 道岔前的退步
- 归属故事：A+B
- 时空 / 视角：傍晚暴雨前，矿镇广场；陆野。
- 场景任务：建立全镇拒绝、旧矿轨西线、周叔的控制权，并触发挡墙危机。
- 即时目标：穿过广场去卫生所见母亲。
- 冲突 `><`：陆野 vs 周叔与退避的乡亲；争夺他是否能进入镇内；周叔暂时占上风。
- 情绪 `+/-`：期待回家 → 被当成灾害隔离。
- 可见行动：乡亲退到警戒线后；周叔攥住道岔钥匙，挡在“东线穿镇 / 西线废石场”的旧牌前；挡墙警报突然响起。
- 退出后果：因此，所有人奔向卫生所撤离，陆野也必须立刻决定走还是留。

## 节拍 5–6 · 争执 / 第二幕衔接点

### S03 · 我只守着她
- 归属故事：A+B
- 时空 / 视角：暴雨初起，卫生所门口；陆野。
- 场景任务：让旧事故压住他，并由他主动选择进入危险区。
- 即时目标：说服周叔允许自己留下保护母亲。
- 冲突 `><`：陆野 vs 周叔；争夺他是否留下；陆野以“不使用能力”的承诺暂时留下。
- 情绪 `+/-`：受辱退缩 → 固执决心。
- 可见行动：周叔把十二年前塌陷留下的弯曲矿灯塞进他手里；陆野摘下英雄徽章，站到卫生所门外。
- 退出后果：因此，他进入能力最不适用的第二世界，并将用“不出手也能守住母亲”证明自己。

## 节拍 7–8 · B 故事 / 乐趣与游戏

### S04 · 救下一个，裂开一面
- 归属故事：A+B
- 时空 / 视角：暴雨中，卫生所院内；陆野。
- 场景任务：兑现“城市救法在故乡制造灾难”，让主题通过代价落地。
- 即时目标：救下雨棚下的孩子，同时守住不用能力的承诺。
- 冲突 `><`：陆野 vs 坠落雨棚与十秒本能反应；争夺孩子安全；陆野救到孩子，却让地层暂时占上风。
- 情绪 `+/-`：克制自信 → 愧疚失控。
- 可见行动：他本能接住雨棚，裂光逼近肩口，只得拍地放力；孩子无伤，诊所墙却随地裂劈开。母亲把孩子拉走，不接受他的邀功。
- 退出后果：因此，乡亲不再让他靠近建筑；主挡墙滑动时，他必须在“什么都不做”和再次冒险之间选择。

## 节拍 9 · 中点

### S05 · 十秒英雄
- 归属故事：A
- 时空 / 视角：暴雨加剧，卫生所后坡挡墙；陆野。
- 场景任务：制造独自强撑的虚假胜利，并启动十秒倒计时。
- 即时目标：用身体稳住挡墙，争取全所撤离。
- 冲突 `><`：陆野 vs 整面滑落挡墙；争夺撤离时间；陆野暂时占上风。
- 情绪 `+/-`：被排斥的无用感 → 以为终于证明自己的振奋。
- 可见行动：他吸收第一波冲击，手臂裂光逐节亮起；人群从他身后撤出，他拒绝周叔靠近。
- 退出后果：因此，他无法放手也无法向脚下卸力，母亲为带出最后一个孩子而被困时，倒计时把所有选择压到一起。

## 节拍 10–11 · 坏蛋逼近 / 一无所有

### S06 · 旧事故重演
- 归属故事：A+B
- 时空 / 视角：同刻，挡墙与卫生所之间；陆野。
- 场景任务：让旧办法造成最严重代价，形成死亡气息。
- 即时目标：在十秒归零前既稳住挡墙又救出母亲。
- 冲突 `><`：陆野 vs 储力上限与空心地层；争夺母亲的生路；地层暂时占上风。
- 情绪 `+/-`：逞强的希望 → 彻底失败。
- 可见行动：他喊周叔开道岔，周叔因东线穿镇拒绝；第十秒前陆野被迫拍地，门廊塌进裂口，母亲、孩子被困，父亲旧矿灯熄灭。
- 退出后果：因此，力量证明彻底失败，陆野只能停下动作，先面对自己一直拒绝承认的问题。

## 节拍 12–13 · 灵魂的黑夜 / 第三幕衔接点

### S07 · 先问一次
- 归属故事：A+B
- 时空 / 视角：雨中的裂口外；陆野。
- 场景任务：让他承认缺陷，并通过询问而非命令得到可执行的共同方案。
- 即时目标：找到不会再次伤人的救母办法。
- 冲突 `><`：陆野 vs 周叔残存的不信任；争夺全镇是否愿意再把道岔交给他；陆野的坦白与让权暂时占上风。
- 情绪 `+/-`：绝望自责 → 谦卑而明确的希望。
- 可见行动：陆野跪下承认自己总替别人决定；在母亲提醒后，他问周叔“哪条线没人”，周叔指出西线，并把清线与切道权留在乡亲手里。
- 退出后果：因此，乡亲主动组成清线链，陆野只能在所有人确认后执行最终传力。

## 节拍 14–15 · 结局 / 终场画面

### S08 · 落力之处
- 归属故事：A+B
- 时空 / 视角：暴雨高潮，旧轨与卫生所；陆野。尾声为灾后同地。
- 场景任务：用已建立规则完成共同救援，并以新行动证明变化。
- 即时目标：把最终塌方安全导向无人废石场，救出母亲和孩子。
- 冲突 `><`：陆野与全镇救援链 vs 最终塌方与十秒上限；争夺卫生所内生命；共同方案占上风。
- 情绪 `+/-`：全镇互不信任 → 有边界的共同接纳。
- 可见行动：乡亲逐段回报“西线清空”，周叔切道，母亲说“放”，陆野才把冲击导入旧轨；远处废石场坍落。灾后他穿救援背心，抬梁前先问“落点清了吗”。
- 退出后果：危机解除；陆野获得的不是无条件原谅，而是以共同规则留在故乡的资格，故事结束。
