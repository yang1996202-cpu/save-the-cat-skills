# 故事核心卡：《落地生灾》（暂定名）

> 本轮按用户授权不停顿推进。凡由创作者尚未确认、但下游必须锁定的决定，均标为“暂定”；本轮后续把这些暂定项当作工作合同，不再暗改。

## 这个点子最不能丢的东西

一个在钢筋城市里落地就能救人的无敌英雄，回到脚下全是废弃矿洞的老家，落地反而会让整座镇子开裂；他第一次必须承认，保护母亲不等于一个人冲上去。

## 一句话故事

城市英雄周擎回到石梁镇，想留下照顾母亲，却因力量会把冲击导入家乡空洞的地层而被全镇视为灾难；当母亲困在即将塌陷的老卫生所里，他必须压住独自硬扛的本能，听从乡亲对地层和旧矿设备的判断，与他们把自己的力量接到基岩上，才能救出母亲而不毁掉故乡。

## 我们跟谁走

- 主角：周擎，常年在大城市救灾、被称为“擎天”的超级英雄。（暂定）
- 他现在的旧办法 / 缺陷：只要有人遇险就立刻用蛮力接管现场；他把“我最强”误当成“我最懂得怎样保护”。
- 为什么观众愿意跟他：他真心想保护母亲，也第一次遇到“越想救人，越可能害死所有人”的无解处境；无敌英雄在母亲面前重新变成一个想回家的儿子。

## 故事为什么必须发生

- 开始时过不去的麻烦：周擎回乡后想留下照顾独居的母亲，但一次习惯性的英雄落地震裂街面，证明他的力量在石梁镇会引发废弃矿洞连锁塌陷。镇民要求他立刻离开，母亲也拒绝让他用“救人”的名义替自己和乡亲做决定。（暂定）
- 看得见的目标：
  - 结果 1 / 期限 / 成功证据：在老卫生所屋顶随地层继续下沉、完全垮塌前，把被横梁压住的母亲救到划定的安全区；观众看到母亲清醒地跨出警戒绳，卫生所随后塌下，目标才算完成。（暂定）
- 对抗力量：正在扩大的矿洞塌陷；周擎一旦直接踩地发力就会加速塌陷；熟悉地层的镇民不允许他再次擅自冲入。镇民不是反派，他们的恐惧有事实依据。
- 失败会伤到的本能需要：母亲的生命、周擎对“家”的归属，以及整个小镇的基本安全。

## 真正的变化

- 他以为自己需要：证明自己的力量足以保护母亲，从而证明自己有资格留下。
- 他真正需要学会：保护不是替别人接管一切，而是先听懂他们知道什么，再把自己的力量交给共同方案。
- 开始状态 → 结束状态：落地就接管现场的“救世主” → 主动停手、询问、服从共同计划的“家里人”。
- 主题观点：真正的保护，不是一个人替所有人决定，而是让力量进入彼此信任的连接。
- 结尾证明变化的行动：危险过去后，周擎没有替乡亲宣布自己要留下；他先问母亲和镇民“我能留下，跟你们一起把矿道加固吗？”，并接过普通的测绘杆步行进队伍。（暂定）

## 故事承诺

- 最接近的故事类型（如有帮助）：最接近“超级英雄型”的反转短剧，核心承诺是超能力的诅咒与身份代价；它不采用同等力量的坏人，因此不是该类型的标准对决版。（暂定）
- 观众期待看到的核心乐趣：城市英雄在老家一落地就成“灾星”的强反差；同一项能力先制造灾难，再因主角改变使用方式而完成救援。
- 这版“似而不同”的地方：要战胜的不是更强反派，而是“无敌就该独自解决”的英雄习惯；家乡不是等待被救的背景，而是掌握解法的一群人。

## 条件性因果契约（仅在故事依赖特殊规则时）

- 触发 / 输入路径：周擎的身体会把自己承受或施加的巨大机械冲击，沿当时与身体连续接触的承力路径传导出去；双脚落地、徒手托举时，力量默认进入脚下地层。（暂定）
- 能做什么：他能承受、托举并重新传递远超常人的重量与冲击；在城市的钢筋基础和连续承重结构中，冲击会被大范围分散，因此看起来近乎无敌。
- 限制 / 代价：他不能让力量凭空消失，也不能在没有承力路径时无限悬空托物；必须先建立一条能够接住力量的连续结构。石梁镇浅层遍布空矿洞，直接向地面传力会把冲击集中到薄弱顶板。
- 危险条件：他在矿洞上方落地、蹬地、托举重物或受重击，都会扩大裂缝并诱发连锁塌陷；力量越大，灾害越快。
- 结尾如何利用已建立规则，而非新增例外：镇口废弃矿井救援架的两根钢柱穿过空洞层、锚在基岩上，旧钢索仍可承重。镇民先验明并架好钢索，把悬吊的周擎接入这条承力路径；他再托起卫生所横梁，冲击经钢索传到基岩，而不是脚下街面。人力绞盘同时拖出母亲。（暂定）

## 待确认

- 暂定选择 1：片名、主角名与“石梁镇 / 废弃矿洞”地域设定。
- 暂定选择 2：把能力锁定为“力量不能消失，只能沿承力路径传导”，并以“锚入基岩的旧矿井救援架”完成前后同规则解法。
- 暂定选择 3：外部目标只保留“屋塌前救出母亲”；“获准留下”只作为关系与主题结果，不另设行政期限。

## 主干五问核对

1. 主角：把蛮力接管误当保护的城市英雄周擎。
2. 难题：他的力量在家乡会诱发矿洞塌陷，越独自救人越可能毁掉小镇；镇民与母亲因此有理由拒绝他。
3. 开始 → 结束：擅自落地接管 → 主动停手、倾听并把力量交给共同方案。
4. 实体目标 / 精神目标：卫生所完全垮塌前救出母亲 / 学会保护必须建立在倾听、信任与共同选择上。
5. 主题：真正的保护，不是替所有人决定，而是让力量进入彼此信任的连接。
