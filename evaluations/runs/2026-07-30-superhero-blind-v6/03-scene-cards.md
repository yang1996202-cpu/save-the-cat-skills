# 场景卡：《落地生灾》（暂定名）

媒介 / 体量：中文短剧，约 3 分钟；6 场，成片预算合计 180 秒。
故事线：无敌英雄回乡后发现自己的力量会引发矿洞塌陷，必须从独自接管改为听取乡亲方案。
A 故事（实体目标）：老卫生所完全垮塌前，把被横梁压住的母亲救到警戒绳外。
B 故事（精神目标）：通过母亲和镇民，学会保护必须建立在倾听、信任和共同选择上。
主题：真正的保护，不是一个人替所有人决定，而是让力量进入彼此信任的连接。

> 暂定补足：陈叔名为陈守山，是退休矿山救护队长；阿杰是会配合他操作旧绞盘的镇民。二人的身份在高潮前可见建立，不到最后临时变成专业人员。成片预算不是故事内倒计时；故事期限仍是“卫生所屋顶完全垮塌前”。

## 节拍 1–3 · 开场画面 / 主题呈现 / 铺垫

### S01 · 英雄落错地

- 时空 / 视角：白天，石梁镇入口的旧矿救援架旁；周擎视角。
- 场景任务：建立周擎的英雄旧习惯、落地即开裂的能力危险、母亲的主题提醒，以及锚入基岩的救援架、旧钢索、操作人员。
- 即时目标：周擎要用一个体面的英雄归来证明自己能留下照顾母亲。
- 冲突 `><`：周擎想以力量让母亲和镇民安心 vs 脚下裂缝、镇民的事实性恐惧和母亲的拒绝；争夺“他的力量在这里是否等于安全”；镇民的恐惧暂时占上风。
- 情绪 `+/-`：自信归来 → 被家乡当成灾星。
- 可见行动：周擎单膝落地，石板裂成蛛网，欢迎横幅随人群一起后退。母亲用拐杖点裂缝，陈守山和阿杰正测试废矿救援架的手摇绞盘；陈守山敲击两根钢柱，说明镇上只有它们穿过空矿层、锚入基岩，周擎仍当众宣布自己要留下。
- 成片预算：30 秒。
- 退出后果：周擎急于用一次实际救助洗掉“灾星”印象，因此下一场面对小险情时会本能出手。

## 节拍 4–5 · 推动 / 争执

### S02 · 一伸手，房子下沉

- 时空 / 视角：紧接上场，老卫生所门前；周擎视角。
- 场景任务：制造唯一外部危机，锁定母亲被困与“屋塌前救出”的目标，同时让镇民有充分理由阻止英雄。
- 即时目标：周擎要接住松脱的石匾，证明自己不会给故乡添乱。
- 冲突 `><`：周擎想立即用力量消除危险 vs 空矿层无法承受他沿双脚导入的冲击；争夺“这次出手会救人还是害人”；地层暂时占上风。
- 情绪 `+/-`：急于证明 → 亲手酿成危机。
- 可见行动：石匾松脱，周擎徒手托住；重量经双脚压入街面，卫生所随闷响倾斜。周兰把一个孩子推出门，自己被前厅横梁压住；陈守山拉起警戒绳，屋顶裂缝仍在延长。
- 成片预算：25 秒。
- 退出后果：母亲被困且屋顶持续开裂，周擎必须在下一场决定是听从警戒还是按旧办法强救。

## 节拍 6–9 · 第二幕衔接点 / B 故事 / 乐趣与游戏 / 中点

### S03 · 越抬越低

- 时空 / 视角：紧接上场，卫生所门洞与下沉的前厅；周擎视角。
- 场景任务：让周擎主动进入反主题世界，完整兑现“无敌英雄越救越灾”，并以虚假胜利把期限收紧。
- 即时目标：周擎要独自抬起横梁，把母亲立即抱出来。
- 冲突 `><`：周擎想靠更大力量抬梁救母 vs 母亲要求他先听陈守山判断、脚下空矿层随发力继续破裂；争夺“谁决定救援办法”；周擎的旧习惯短暂占上风，随后被地层反噬。
- 情绪 `+/-`：强行掌控 → 无力失控。
- 可见行动：周擎扯断警戒绳踏入前厅；周兰不配合他拽腿，指向陈守山标在地上的矿道线。他仍双脚撑地托梁，横梁一度抬高，母亲刚抽出半条腿，地面便再沉半尺，墙灰齐落、主梁逐段开裂，母亲重新卡死。
- 成片预算：35 秒。
- 退出后果：直接托举已被证明会加速屋塌；裂缝又逼近门外人群，周擎下一场必须承受继续逞强的群体代价。

## 节拍 10–12 · 坏蛋逼近 / 一无所有 / 灵魂的黑夜

### S04 · 把手离开地面

- 时空 / 视角：紧接上场，卫生所门外警戒区；周擎视角。
- 场景任务：让周擎的旧办法造成最低谷，并完成从“继续发力”到“承认必须先听”的内部转折。
- 即时目标：周擎要在顶板落下后再次冲回母亲身边。
- 冲突 `><`：周擎想本能撑地、强行重返前厅 vs 新裂缝正冲向镇民且母亲短暂失去回应；争夺“他能否停下唯一会用的办法”；对他人的责任迫使他停手。
- 情绪 `+/-`：绝望躁进 → 羞愧停手。
- 可见行动：顶板砸下隔断母子，周兰没了声音；周擎伸手撑地准备发力，新裂缝掀倒警戒绳旁的阿杰。周擎硬生生抬起双手，任陈守山把他拖出下沉区，承认自己在城里救人从来不问；陈守山点出“劲没错，路错了”。
- 成片预算：25 秒。
- 退出后果：周擎终于愿意询问承力路径，下一场才可能把既有能力与既有救援架组合成解法。

## 节拍 13–14 · 第三幕衔接点 / 结局

### S05 · 把力量交给一条路

- 时空 / 视角：紧接上场，旧矿救援架与卫生所之间的连续救援区；周擎视角。
- 场景任务：用前置人员、设备和同一套传力规则完成协作救援，并给实体目标一个可见闭合点。
- 即时目标：周擎要在屋顶垮塌前，按镇民确认的承力路径托梁，让众人拖出母亲。
- 冲突 `><`：周擎、陈守山和阿杰想把冲击经钢索送入基岩、救出周兰 vs 持续开裂的屋顶、旧绞盘承重过程和周擎再次擅自落地的本能；争夺“解法能否在屋塌前建立并保持”；共同方案最终占上风。
- 情绪 `+/-`：谨慎试信 → 协作成功。
- 可见行动：周擎先问“哪条路能接住我的劲”，陈守山指向救援架；陈守山验索扣、阿杰就位摇柄，二人把钢索扣上周擎并将他吊离空洞层。周擎抓住横梁，等陈守山喊“基岩吃上力了”才抬；钢索绷直、钢柱震动而街面不再开裂。镇民拉出周兰，她清醒越过警戒绳，下一瞬卫生所屋顶垮下；周擎继续悬吊，等陈守山确认落点后才落地。
- 成片预算：50 秒。
- 退出后果：母亲在期限内获救，唯一实体目标以“越线后屋塌”的先后关系明确完成；周擎是否能留下不再是力量证明，而要由关系选择回答。

## 节拍 15 · 终场画面

### S06 · 先问，再落脚

- 时空 / 视角：片刻后，卫生所外安全区；周擎视角。
- 场景任务：让周擎用一个不同于开场的行动证明改变，并把“留下”收束为关系结果而非第二项任务。
- 即时目标：周擎想请求母亲和镇民允许他留下参与矿道加固。
- 冲突 `><`：周擎想回家但不再愿意擅自替大家决定 vs 他尚未得到母亲和镇民的明确接纳；争夺“留下是英雄宣告还是共同同意”；相互信任最终占上风。
- 情绪 `+/-`：忐忑无归 → 被接纳为家里人。
- 可见行动：周擎问“我能留下，跟你们一起把矿道加固吗”；周兰不替全镇回答，只看向陈守山。陈守山把普通测绘杆递给周擎，在前方标出落脚点；周擎收起披风，跟着队伍一步一步走。
- 成片预算：15 秒。
- 退出后果：故事闭合在“他仍有力量，但不再独自决定力量落在哪里”的新世界。

## 场景层回检

- 场次与体量：6 场，30 + 25 + 35 + 25 + 50 + 15 = 180 秒；没有为十五拍制造十五场。
- 因果链：落地开裂引出证明冲动 → 托匾导致母亲被困 → 强救加速塌陷 → 群体代价迫使停手 → 询问后组合既有资源 → 获救后请求共同接纳。
- 每场主要冲突：6 场均只有一个主要争夺点，并各有一次首尾情绪 / 价值变化。
- 中点后升级：从母亲受困升级到屋顶连续开裂，再到裂缝威胁人群与母亲失去回应；不是换地点重复同一阻碍。
- 能力输入与输出：S01、S02、S03 可见建立冲击从身体接触面进入脚下；S05 先让钢索连续接触周擎，再通过救援架输出至基岩，输入路径未被跳过。
- 高潮资源与人员前置：S01 已建立救援架锚入基岩、旧钢索、退休救护队长陈守山和绞盘操作人阿杰；S05 只调用已在场且已具备能力的人与物。
- 目标闭合：S05 明确呈现母亲清醒越过警戒绳，随后屋顶才垮塌；没有用“危险停止”代替“人已获救”。
- 时空分场：S01 镇口救援架旁、S02 卫生所门前、S03 门洞与前厅、S04 门外警戒区、S05 连续救援区、S06 片刻后的安全区；明确的地点推进或时间跳转均另起场，连续救援动作没有塞入事后尾声。
- 体量减法：只新增执行所需的陈守山与阿杰身份，不增加反派、第二灾难、专业新设备或精确秒表；“留下”只在尾声用一个请求与递杆动作收束。
