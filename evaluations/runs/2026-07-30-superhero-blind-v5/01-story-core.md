# 故事核心卡：《回乡禁令》（暂定）

> 本轮按用户授权连续创作，所有未确认的具体设定均标为“暂定”，供成稿后整体取舍。

## 这个点子最不能丢的东西

一个在城市里靠力量解决一切的无敌英雄，回到最想归属的故乡，却必须证明“会克制的力量”才配留下来保护家人。

## 一句话故事

能吸收并释放冲击力的城市英雄陆峥回到惧怕他的山镇，想赶在末班车发车前撤销驱离令、留下照顾母亲；当暴雨令泄洪闸失灵、母亲被困老屋，他必须对抗洪峰、全镇的不信任和自己“一拳解决”的旧习，在九十秒内与应急人员合作，既救出母亲又安全开闸，以克制而非蛮力赢回留下的资格。

## 我们跟谁走

- 主角：陆峥，32 岁，能吸收、储存并释放动能的城市超级英雄（暂定）。
- 他现在的旧办法 / 缺陷：把“保护”理解成替所有人做决定、用最大力量最快解决；他不求助，也不相信普通人的专业能跟上自己。
- 为什么观众愿意跟他：他在外被全城欢呼，回家却连母亲的门都不敢敲；强大与无处可归同时发生，而他留下的愿望不是荣誉，是陪母亲过日子。

## 故事为什么必须发生

- 开始时过不去的麻烦：陆峥童年第一次失控救人时，释放的震波震塌半条老街；如今镇民把每次裂缝都算在他头上。镇防灾委员会已签驱离令，母亲也拒绝让他用力量替自己安排生活。
- 看得见的目标：
  - 结果 1：母亲安全离开受损老屋；期限：镇应急站报出的洪峰抵达前 90 秒；成功证据：母亲越过黄色安全线，并由现场医护确认可自主站立、无致命伤。
  - 结果 2：打开卡死的旧泄洪闸、保住低洼老街；期限：同一 90 秒倒计时归零前；成功证据：闸门升至绿色刻度，水位从红线回落，警报解除。
  - 结果 3：获得留在镇上照顾母亲的合法许可；期限：18:00 末班车关门前（危机开始时剩约 2 分钟）；成功证据：镇防灾委员会主任当众撕毁驱离令，并把应急志愿员钥匙交给他。
- 对抗力量：逼近的洪峰与老旧设施；以周主任为代表、基于真实旧伤的不信任；陆峥遇事就全力出手的惯性。
- 失败会伤到的本能需要：母亲和镇民的生存安全，以及陆峥对家庭、故乡与归属的需要。

## 真正的变化

- 他以为自己需要：证明自己比灾难更强，让所有人不得不接受他。
- 他真正需要学会：保护不是压过别人的恐惧，而是在共同规则里克制、求助并承担后果。
- 开始状态 → 结束状态：孤身扛下一切、把人当成待救对象 → 把力量交进团队方案、把母亲当成能选择的合作者。
- 主题观点：真正可靠的强大，不是永不失手，而是愿意让力量接受他人的边界与共同约束。
- 结尾证明变化的行动：拿到留下的钥匙后，他不再宣告“由我保护这里”，而是先问母亲是否愿意让他住回家；随后接受冯队长安排，以普通应急志愿员身份排在队尾搬沙袋。

## 故事承诺

- 最接近的故事类型（如有帮助）：超级英雄型（暂定），以“诅咒/弱点”而非强敌对轰作为三分钟短剧的核心；兼有“被制度化型”的个人与共同规则冲突，但不另立次类型合同。
- 观众期待看到的核心乐趣：无敌英雄面对“不能出拳”的难题；同一能力从灾难源变成精准工具；母子之间一句比打斗更难的请求。
- 这版“似而不同”的地方：敌人不是更强的超能力者，而是英雄过去真实造成的集体创伤；高潮不是升级力量，而是把力量接入消防队、旧绞盘和镇级授权组成的普通人方案。

## 条件性因果契约（故事依赖特殊规则）

- 触发 / 输入路径：陆峥必须以裸露皮肤直接接触正在运动或震动的物体，才能吸收其动能；输入后手臂会出现由蓝转红的发光纹路，旁人可见剩余承载状态。
- 能做什么：在身体承载上限内停止冲击、坠落或震动；之后可从手掌或脚底把已储存的动能定向释放给正在接触的物体，使其直线移动或轴向转动。
- 限制 / 代价：他不能创造动能，也不能让动能凭空消失；每次吸收后必须在 20 秒内释放，超过上限会肌肉痉挛、失去定向能力。精细释放需要稳定接触和外部人员给出明确方向。
- 危险条件：把大量动能直接释放进松软地基、砖木老屋或人群附近，会形成扩散震波；这正是童年事故和镇民恐惧的来源。
- 结尾如何利用已建立规则，而非新增例外：陆峥先接触闸门吸收洪水撞击，冯队长用预先展示的钢缆把旧绞盘与闸门轴固定，周主任用钥匙解锁获准开启的分洪渠；陆峥在 20 秒窗口内把储能定向释放进绞盘轴，借轴向转动升闸。团队提供方向、资源与权限，他只提供规则内的能量。

## 主干五问核对

1. 主角：把蛮力当保护的动能英雄陆峥。
2. 难题：故乡把他的能力视为真实灾害，他还会重复造成灾害的旧办法。
3. 开始 → 结束：孤身证明自己无敌 → 在规则与关系中克制、求助、共同承担。
4. 实体目标 / 精神目标：限时救母、开闸并取得留下许可 / 学会尊重边界、把力量交给团队使用。
5. 主题：力量接受共同约束，才可能成为可信的保护。
