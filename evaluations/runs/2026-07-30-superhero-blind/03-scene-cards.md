# 场景卡：《把力气收回来》

媒介 / 体量：3 分钟中文短剧；6 场
故事线：城市无敌英雄回乡求留，却必须学会不用力量替别人做决定
A 故事（实体目标）：保住母亲和鹤湾，并获得留下来的资格
B 故事（精神目标）：通过母亲与乡亲学会克制、倾听和共同承担
主题：真正的保护是共同承担，而不是替别人做决定

> 暂定：场景数量、人物姓名和具体地点未经逐项确认；所有场景均沿用上游合同。

## 节拍 1–3 · 开场画面 / 主题呈现 / 铺垫

### S01 · 城市英雄接到家里的电话

- 时空 / 视角：白天，城市高架下；陈曜。
- 场景任务：建立陈曜在城市里“用力即可解决、所有人都会服从”的旧世界，并把他推向老家。
- 即时目标：接住坠落钢梁后，立刻替母亲安排暴雨撤离。
- 冲突 `><`：陈曜想让母亲按他的方案离开 vs 周岚坚持自己能处理；争夺“谁有权决定她是否撤离”；陈曜用行动抢先占上风。
- 情绪 `+/-`：自信受欢迎 → 笃定却被拒绝。
- 可见行动：陈曜吸收钢梁冲击，在欢呼中接电话；听到暴雨和水塔隐患后，不再询问，直接动身。
- 退出后果：因此，他带着尚未释放干净的冲击回到鹤湾。

## 节拍 4–5 · 催化剂 / 争执

### S02 · 一落地先震裂了家

- 时空 / 视角：傍晚，鹤湾周家院外；陈曜。
- 场景任务：让能力在老镇第一次变成灾难，并建立乡亲拒绝他的现实阻力。
- 即时目标：顺利回家，把母亲带离危险区。
- 冲突 `><`：陈曜想立即带走母亲 vs 周岚和乡亲要求他先停止擅自营救；争夺“他是保护者还是风险源”；乡亲暂时占上风。
- 情绪 `+/-`：急切归家 → 羞愧受拒。
- 可见行动：他落地卸力，裂纹沿青砖爬上院墙，水管爆开；乡亲后退，周岚关掉他替自己收拾的行李箱。
- 退出后果：因此，陈曜必须证明自己的力量能在这里派上用场。

## 节拍 6–8 · 第二幕衔接点 / B 故事 / 乐趣与游戏

### S03 · 他又说“我一个人来”

- 时空 / 视角：傍晚，旧水塔下；陈曜。
- 场景任务：让陈曜主动进入反主题世界，并用一次表面成功兑现反差前提。
- 即时目标：独自扶正倾斜水塔，换取乡亲允许他留下。
- 冲突 `><`：陈曜要清场后独自处理 vs 周岚拿旧矿图要求他听方案；争夺营救的主导权；陈曜暂时占上风。
- 情绪 `+/-`：被质疑 → 重新掌控。
- 可见行动：他把乡亲推到警戒线外，按住塔身释放冲击；水塔归位，远处井盖和窗框却接连震动。
- 退出后果：因此，藏在地下的回震即将把假胜利翻成真实代价。

## 节拍 9–11 · 中点 / 坏蛋逼近 / 一无所有

### S04 · 最想保护的人被他震伤

- 时空 / 视角：连续，水塔旁与周岚的小诊所；陈曜。
- 场景任务：让假胜利立刻伤到母亲，把“证明有用”升级成不可逆的关系和生命危机。
- 即时目标：在二次塌落前救出被门梁压住的母亲。
- 冲突 `><`：陈曜想再次用冲击弹开门梁 vs 脆弱建筑承受不了第二次释放、周岚也拒绝他继续硬来；争夺“他能否克制本能”；环境暂时占上风。
- 情绪 `+/-`：短暂得意 → 彻底自责。
- 可见行动：陈曜看见裂缝从水塔一路窜到诊所；他改用双手缓慢抬梁救出母亲，随后摘下胸前标志，准备离开。
- 退出后果：因此，他在最低谷失去留下的理由，而暴雨中的水塔又突然断裂，逼他立刻选择。

## 节拍 12–13 · 灵魂的黑夜 / 第三幕衔接点

### S05 · 母亲让英雄听完

- 时空 / 视角：连续，断裂水塔下；陈曜。
- 场景任务：让陈曜说出独断背后的恐惧，并主动接受共同营救方案。
- 即时目标：在水塔坠落前找到不会把冲击释放进老镇的办法。
- 冲突 `><`：陈曜认定只能独自接塔后把力量释放，或立即带母亲逃走 vs 周岚要求他听从全镇协作方案；争夺“是否把控制权交给别人”；周岚暂时占上风。
- 情绪 `+/-`：绝望想逃 → 害怕但愿意信任。
- 可见行动：周岚摊开旧矿图，乡亲搬来绳索、木楔并发动旧卡车；陈曜停止打断，摘下手套，把绳结交给周岚检查。
- 退出后果：因此，最后营救将由陈曜承受冲击、全镇负责卸力共同完成。

## 节拍 14–15 · 结局 / 终场画面

### S06 · 镇子也接住了英雄

- 时空 / 视角：暴雨中水塔下，随后是雨后的周家院外；陈曜。
- 场景任务：用共同营救完成外部胜利，并用“先问再留”的行动证明内部变化。
- 即时目标：把水塔安全放平，同时不把吸收的冲击释放给老镇。
- 冲突 `><`：陈曜要把冲击困在体内直到乡亲完成卸力 vs 身体濒临失控、旧习惯催促他独自爆发；争夺“力量由谁、以什么方式承担”；陈曜与乡亲共同占上风。
- 情绪 `+/-`：孤身濒临崩溃 → 被众人接住并谨慎接纳。
- 可见行动：陈曜接住塔身不释放，乡亲收绳、卡车倒退、周岚打入木楔；水塔落地后众人用木梁替他把余力缓慢卸进泥地。雨停后，他扶着修墙的梯子，先问母亲能否留下，再接过乡亲递来的泥刀。
- 退出后果：因此，鹤湾没有把他重新捧成神，只允许他作为需要守规矩、也会被帮助的一员开始修复家园。
