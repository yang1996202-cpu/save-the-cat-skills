# 创作主流程（救猫咪·端到端编排器）

你拿到用户的一个故事方向。你的任务不是一口气写出全稿——LLM 长篇会失焦、人物声音会糊、节拍会变形。你的任务是当**导演**：按救猫咪方法论，分阶段把方向"洗"成完整作品，每个阶段产出可检查的中间物，**用户确认后才进下一步**。

为什么必须分阶段：斯奈德原话——"如果还不能用一两个句子阐明每个节拍，那我还没理清节拍，我只是在猜测，我在踩水即将被淹。"端到端一口气写 = 全程踩水。分阶段 = 每一拍想清楚再下沉。这契合他自己的工作法：案板、索引卡、一拍一拍填，不是一气呵成。

## 流程：7 个阶段，每阶段交付 + 确认

### 阶段 0 · 方向澄清
- 把用户的方向复述成一句话故事线雏形。
- 问清：什么媒介（剧本/小说/短篇/短视频/文章）？大致体量？目标受众？
- 产出：一份"创作简报"。
- → 用户确认后进阶段 1。

### 阶段 1 · 点子验证（调用 stc-idea-check）
- 跑 stc-idea-check 全套：四要素体检 + 十类型识别 + 主干5问 + 原始性初筛 + 改写故事线。
- 产出：验证报告 + 定稿故事线 + 类型 + 主干5问答案。
- 任一关没过 → **不进下一步**，先用 stc-first-aid 急救或回去改方向。
- → 用户确认故事线立得住后进阶段 2。

### 阶段 2 · 三个世界图景
- 画第一世界 / 第二世界 / 第三世界三个快照（方法见 stc-beatsheet 的"先画三个世界"）。
- 重点检验：第二世界是否和第一世界"相反"？第三世界主角"变成谁"是否清楚？转变幅度够不够？
- 产出：三世界快照表。
- → 用户确认转变想透了后进阶段 3。

### 阶段 3 · 节拍大纲（调用 stc-beatsheet）
- 跑 stc-beatsheet 出 BS2 15 拍大纲，每拍 1-2 句，标 A/B 故事、冲突 `><`、情绪 `±`。
- 产出：完整节拍表。
- → 用户确认大纲后进阶段 4。

### 阶段 4 · 分场写作
- 把 15 拍拆成具体场景（电影约 40 场；其他媒介按体量换算）。
- **一场一场写，不要一次全写。** 每场：一个冲突、一个情绪转变、示而不讲。
- 每写完一组（如第一幕全部场景），让用户看，确认声音/基调对路再继续。
- 人物台词过"劣质台词检测"（盖住名字能分辨谁说话）。
- 产出：分场剧本/正文。
- → 用户确认后进阶段 5。

### 阶段 5 · 自检回改（调用 stc-diagnose）
- 跑 stc-diagnose：主干5问 + 9条检查 + 绿灯50问逐拍 + 专项检测（示而不讲/坏蛋强度/台词/转折）。
- 产出：弱点清单 + 改写优先级。
- 按优先级回改（致命 → 重要 → 润色），先改致命的。
- → 用户确认改完后进阶段 6。

### 阶段 6 · 推介（调用 stc-pitch）
- 跑 stc-pitch 出一句话 logline + 贝蒂7点推销稿（口头版 + 文字版）。

## 持久化（跨多轮的关键）

长流程会跨多轮对话。**每个阶段产出写到文件**，建议建作品项目目录：

```
~/projects/build/products/<作品名>/
├── 01-brief.md          # 阶段0 创作简报
├── 02-idea-check.md     # 阶段1 验证报告
├── 03-three-worlds.md   # 阶段2 三世界快照
├── 04-beatsheet.md      # 阶段3 节拍表
├── 05-scenes/           # 阶段4 分场（每场一文件或分幕）
├── 06-diagnose.md       # 阶段5 诊断+回改记录
└── 07-pitch.md          # 阶段6 推介稿
```

下次继续时，**先读这些文件恢复上下文**，不要让用户重述。问一句"上次到阶段 X，确认进下一步吗"即可。

## 什么时候不用这个 skill

- 用户只想做其中一环（只要大纲 / 只要诊断 / 只要推介）→ 直接用对应分段 skill，别套全流程。
- 方向还很模糊、用户自己也没想清要写什么 → 先用 stc-first-aid 理方向，别硬跑全流程。
- 用户明确"一键出全稿不要我确认" → 提醒风险（长篇会失焦），若坚持可压缩确认节点，但质量自负。

## 注意

- **编排模式：内联执行 + 可触发子 skill。** Claude Code 里一个 skill 不能强制加载另一个，所以本 skill 不能假设 stc-idea-check 等子 skill 一定会被触发——因此每个阶段都给了**方法摘要级**描述，让 Claude 凭摘要内联执行就能跑通。如果对应子 skill 恰好被加载，按它的完整版执行更准。母 skill 不重复完整框架，只到摘要级。
- 每个阶段的"确认节点"是硬节点，不要跳过——跳过 = 退回踩水模式。
- 媒介不是电影时，阶段流程不变，把"页码/场景/剧本"换成对应媒介单位。
- 不脑补原书没有的方法。流程里的每一步都对应原书的某个固定框架（主干5问/三世界/BS2/绿灯清单/7点推销）。
