# 救猫咪故事 skill 套件

基于布莱克·斯奈德《救猫咪》三部曲提炼的 5 个 skill。目标是忠实整理原书方法论，**不脑补**——所有方法标注书原文出处，任何延伸明确标注。

**1 个编排器 + 4 个分段工具**：`stc-create` 是端到端创作主流程（导演），调度下面 4 个分段 skill。只想做一环就直接调分段 skill；想从方向一路写成完整作品就用 stc-create。

## 5 个 skill

| 类型 | skill | **作用对象** | 场景 | 输入 → 输出 |
|---|---|---|---|---|
| 🎬 编排器 | `stc-create` | 创作流程 | 给个方向，从零一路写成完整作品 | 方向 → 多阶段流水线（分阶段交付+确认）|
| ① 点子 | `stc-idea-check` | 点子 | 动笔前验证点子立不立得住 | 点子 → 四要素+十类型+主干5问+原始性+改写故事线 |
| ② 结构 | `stc-beatsheet` | 结构 | 要动笔了，搭结构骨架 | 点子 → 三世界图景 + BS2 15节拍 + 7点对外推介 |
| ③ 查改 | `stc-diagnose` | **故事文本** | 写完/卡住，查问题改稿 | 故事文本 → 主干5问+9条检查+绿灯50问+专项检测 |
| ④ 心法 | `stc-first-aid` | **创作者本人** | 卡壳/没灵感/怀疑自己/定方向 | 困境 → 对应急救法 + 下一步动作 |

### 一句话区分 diagnose 和 first-aid（最易混的两个）
- **故事有病**（主角太扁/坏蛋弱/缺中点/台词无聊）→ `stc-diagnose`
- **写故事的人卡了**（没灵感/怀疑自己/不知道为啥写/定不下方向）→ `stc-first-aid`

## 端到端流程

完整流程定义见 `stc-create/SKILL.md`（方向澄清 → idea-check → 三个世界 → beatsheet → 分场写作 → diagnose → 对外钩子[可选]，每阶段交付 + 用户确认 + 失败即停）。流程只在 stc-create 一处定义，本文件不重复。

## 书原文 vs 整理者延伸

本套件忠实整理原书方法论，区分如下，使用者可自行核查：

**完全是原书固定框架（📖 书原文）**：
- BS2 15 节拍（节拍名、页码、定义）——第 1/2 册
- 十类型（每类 3 元素 + 3 判断标准）——第 2 册
- 主干 5 问、9 条检查、绿灯 50 问清单——第 3 册
- 一句话故事线四要素、主角/坏蛋形容词配方——第 1 册
- stc-first-aid 的 5 剂方法（强行编造 / 30 清单 / 愿望卡行动卡 / 规训重点正能量 / 你就是故事）——第 3 册，各剂行号见 `stc-first-aid/SKILL.md`

**整理者的组织或延伸（非书原文，已在各 skill 内标注）**：
- 把原书内容按"使用场景"切成 5 个 skill——这是整理者的组织方式，不是原书结构。
- **三个世界**——摘抄只有一句引用、缺第 3 册第三章原文，定义补自 savethecat.com 官网第三章 PDF（Transformation Machine）。
- stc-first-aid 各剂"方法→卡点"的映射——急救 1（强行编造→为主角编难题）忠于书原意；已剔除"把强行编造挪去当'找写作动机'"这个过度延伸。
- 媒介换算建议（电影→小说/短视频）——整理者加的适用说明，非原书。

## 核心概念速查

- **主干5问**（理直脊柱，诊断用）：谁是主角 / 难题是什么 / 怎样开始结束 / 实体精神目标 / 主题是什么
- **三个世界**（转变机器，结构用）：第一世界（原本的世界）→ 第二世界（颠倒的反主题世界）→ 第三世界（综合后的全新世界）。三个世界的差异 = 主角的转变幅度。
- **BS2 15节拍**：开场画面/主题呈现/铺垫/催化剂/争执/第二幕衔接点/B故事/游戏/中点/坏蛋逼近/一无所有/灵魂黑夜/第三幕衔接点/结局/终场画面
- **A/B故事**：A=实体目标(剧情) / B=精神目标(主题)，必须编结
- **原始吗**：全书试金石——驱动力是否落到生存/饥饿/性/保护所爱/死亡恐惧

## 对外推介速查（套件级，不属于任一 skill）

推介不属于"验证点子/搭骨架/诊断/急救"任何单一场景，是横跨的对外动作，速查放这里。推介的硬核是 `stc-idea-check` 的一句话 logline（四要素+配方）；要展开讲，用 `stc-beatsheet` 节拍表里的 7 个关键拍当骨架，每拍 1-3 句：

**开场画面**（主角是谁）→ **催化剂**（什么打破世界）→ **第二幕衔接点**（精华/海报，对方记住的那句）→ **中点**（复杂挑战）→ **一无所有**（怎样失去所有）→ **第三幕衔接点**（怎么反击）→ **终场画面**（转变成谁）。

**讲完闭嘴**——讲完就停，不补充、不自贬、不解释，等对方提问。（原书第3册贝蒂·瑞恩方法）

## 设计原则

- **按使用场景切 skill，不按框架维度切**：避免同一原则在多个 skill 重复。
- **忠于原书、不脑补**：所有方法标注书原文出处；任何延伸必须标 ⚠️ 并说明。
- 演进记录：
  - 2026-07-29 初版 6 skill（含 stc-pitch）。
  - 审查发现 stc-pitch 内容 90% 是 idea-check(logline)+beatsheet(7点节拍) 的重组、且"卖剧本给制片人"场景与内容创作场景不匹配——删除 stc-pitch，7点推销并入 beatsheet，套件精简为 5 skill。
  - 核实 stc-first-aid：方法虽全在原书，但"方法→卡点"映射有未标注延伸（强行编造被挪用到"找写作动机"）——已逐剂标注书原意+行号、剔除过度延伸，并明确 first-aid(治人) 与 diagnose(治文本) 的边界。
  - 7 点推介从 beatsheet 独立小节移到 README 速查——beatsheet 回归单一职责（只搭骨架）；推介是横跨的对外动作，不属于任一分段 skill，故放套件级 README。

## 数据来源

原书方法论来自《救猫咪》三部曲划线笔记（197 条，三本合一）。三个世界定义补自 savethecat.com 官网第三章 PDF。各 skill 引用的原文框架均为原书固定术语，未做臆造。

## 适用范围

原书针对电影剧本，但框架适用于任何有"主角-目标-转变"的叙事：小说、短视频脚本、文章、内容产品。使用时把"片名/页码/成本"等电影专属词换成对应媒介刻度即可，结构原则不变。**（媒介换算的统一规则集中在此，各子 skill 不再重复此条。）**
