# 故事创作共同契约

这是母 skill 与各子 skill 之间的交接契约，不是新增一套“万能公式”。它把《救猫咪》反复出现的创作主线翻成小白也能看懂的共同语言。

## 原书主干五问的跨阶段交接

1. **谁是主角**：观众从头到尾主要跟随谁？
2. **难题是什么**：故事开始时，他本人和他的世界哪里已经过不下去；谁或什么在阻止他？
3. **怎样开始、怎样结束**：他从什么状态变成什么状态；结尾用哪个不同于开头的选择证明变化？
4. **实体目标和精神目标是什么**：他眼下非得到什么不可；他真正需要学会什么？
5. **这部作品是关于什么的**：主题要表达什么可被故事挑战的观点？

“对抗力量”和“结尾证明动作”是为了让五问能交给下游执行而展开的字段，不是原书新增的第六、第七问。

## 从头问到尾：“原始吗？” `[摘录]`

摘录 129–135、261 把“原始吗？”称为剧本创作和修改的试金石。这里的“原始”不是粗糙、低俗或题材简单，而是：**人物表面的愿望，能否落到普通人不需要专业背景也能本能理解的需要。**

使用时做一次向下剥离：

```text
表面目标 → 为什么非得到不可 → 失败会失去什么 → 原始驱动力
```

原书列举的根部包括生存、饥饿、性、保护所爱之人、死亡恐惧，也包括被爱、寻找伙伴、保护家园和正义复仇。这些是例子，不是封闭分类；不要为了套词把所有目标都硬改成“生存”。

这条原则同时检查主角、对手、重要配角和次情节：

- 主角的目标为什么值得观众本能地在乎？
- 对手和配角是在为自己的需要行动，还是只替作者推动情节？
- 次情节是否触及可以理解的人类愿望，还是只剩功能和信息？
- 把职业、制度和抽象任务拿掉后，人物行为还像正常人吗？

原文中的生物学与 DNA 说法保留为作者的比喻，不扩展成科学结论、评分公式或新的强制分类。阅读者写下的“生物密码”等总结属于个人理解，不冒充作者原法则。

## 共同目标

每个阶段都服务于同一个故事，不为完成自己的表格而增加内容：

- 点子阶段确认前提站得住，故事确实有值得跟随的人、麻烦与变化。
- 结构阶段让主角的选择和代价推动转变，并兑现点子许下的故事承诺。
- 场景阶段把冲突、行动和变化真正写出来，不用解释替代戏。
- 改稿阶段先处理最影响整部故事的问题，再处理局部表达。

原书的方法帮助创作者把故事想清楚、写出来、再重写；任何表格或流程都不是好故事的保证。

## 创作主线

可以把整条故事理解成：

> 一个带着缺陷、用旧办法生活的人，为了一个看得见的目标采取行动；阻力不断升级，旧办法最终让他付出最大代价；他领悟真正需要的东西，并在最后用新的选择解决核心冲突，证明自己已经改变。

这是 `[整理者延伸]`：它是对上述摘录的工作化归纳，不是作者给出的固定句式。使用时允许故事反向转变、悲剧结局或群像，但仍要说清“谁发生了什么变化”。

## 场景推进最小单位

每场正文至少形成一次：

> 想要什么 → 遇到阻碍 → 做出行动或选择 → 局面发生转变 → 结果迫使下一场发生

其中“一个主要冲突”和“首尾情绪变化”来自摘录 197、199；“即时目标、选择、退出后果”是 `[整理者延伸]`，用于保证场景能被继续写、继续拍。

## 各阶段只交付一个东西

| 阶段 | 唯一交付物 | 不在本阶段做 |
|---|---|---|
| 点子发展 | 可确认的故事核心 | 不铺十五节拍、不写正文 |
| 节拍结构 | 三个世界 + BS2 十五拍 | 不拆逐场、不润色台词 |
| 场景规划 | 可逐场写作的场景卡 | 不写完整场景、不做分镜 |
| 场景写作 | 依据已确认场景卡写出的场景正文 | 不偷偷改故事主干、不拆镜头 |
| 故事诊断 | 有证据的优先级改稿单 | 不替作者重搭整部作品 |
| 创作急救 | 一个解除当前卡点的动作 | 不诊断文本、不做职业规划 |

## 面向小白的语言

- 首次出现术语时先说人话，再补术语。例如：“打破原生活的那件事（催化剂）”。
- 不用评分表代替创作。先给可选方向和示例，让用户做选择；确认后再检查是否站得住。
- 不把电影页码当其他媒介的硬规则。
- 不把类型、十五拍和场景卡说成成功保证；它们是帮助想清楚和发现缺口的工具。
