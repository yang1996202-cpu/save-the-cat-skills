# 故事诊断与重写器（救猫咪·查改阶段）

你拿到用户已写好的故事（或部分）。原书第3册的核心立场：**"没有问题"才是问题**——如果剧本沉闷或读者反馈不认同，那剧本就有问题，可以查。诊断不是挑刺，是用普遍性真理给"绿灯"或定位弱点。

先做 3 步前置，再做逐拍诊断，最后给改写优先级。

## 前置 1：主干 5 问速过

先过一遍 `stc-idea-check` 第 4 步的"主干 5 问"（谁是主角 / 难题是什么 / 怎样开始结束 / 实体精神目标 / 主题），并用确定主角的五条标准验证主角选得对不对：和我们最相像 / 最大叙事弧线 / 学到最多 / 最不想改变 / 最需要改变。

任何一问答不出，故事就没脊柱，后面逐拍诊断意义不大——回去先用 `stc-first-aid` 或 `stc-idea-check` 补。

## 前置 2：读绿灯检查清单

读 `references/greenlight-checklist.md`——这是原书第3册的 50 个问题，按 15 节拍逐拍提问 + "提高标准"三问。这是逐拍诊断的主清单。

## 前置 3：9 条检查

原书第1册的简便检查法。觉得剧本沉闷或反馈不认同时，逐条问：

1. **主角引领动作了吗？** 每个阶段是否积极？是否因愿望/目标激发？
2. **人物"说情节"了吗？** 是透过人物长篇大论，还是用动作展示？
3. **坏蛋足够坏了吗？** 是否给主角合适挑战？与影片匹配？
4. **中点之后情节提速了吗？** 强度增加？第三幕结尾主角和坏蛋有更多东西揭示？
5. **剧本情绪是否单调？** 纯正剧/纯喜剧/纯悲剧/全挫折？缺情绪中断吗？
6. **台词乏味吗？** "劣质台词检测"后每个人说话方式还一样吗？能只凭说话方式辨别人物吗？
7. **次要人物有区别吗？** 能凭外表记住区别？言谈举止外貌是否独一无二？
8. **主角旅程起点是否尽量往后退了？** 能看到主角情感成长的整个历程吗？
9. **原始吗？** 人物本质由原始愿望（被爱、生存、保护家庭、复仇）激发吗？

## 逐拍诊断

对故事的每个节拍（按 BS2 的 15 拍），用绿灯清单的对应问题检查，标 ✅/⚠️/❌ + 问题 + 改写方向。

## 专项检测（原书金科玉律）

这些是原书反复强调的"不可违背的法则"，单独跑：

### 示而不讲（show don't tell）
原书：电影用影像讲故事，能画面表现时别用台词。例："丈夫沿街走时眼睛离不开漂亮女孩"比三页对话说明他们走上离婚法庭强多了。想让我们知道两人刚打完架？让他们谈任何事，就是别谈打架。**发现"说情节"——标记改写为画面/动作。**

### 救猫咪 / 让对手更坏
另类主角或复仇主角要获得认同：**只要让他的对手更坏就可以了**。《低俗小说》里特拉沃塔是杀手，但他老大的凶狠（足底按摩就被扔出窗外）让他显得小儿科——喜欢与憎恶达到完美平衡。检查：主角不讨喜时，坏蛋够不够坏？

### 坏蛋强度
坏蛋与主角技巧力量应差不多，但**坏蛋要稍稍比主角强一点**（他会不择手段，已放弃家庭价值观）。不是不可战胜——只是看似不可能的挑战。坏蛋占优，主角击败他时被抬高。

### 劣质台词检测
原书方法：拿一页剧本，**盖住说话者名字**，来回读若干人物的台词。不看名字能分辨说话者是谁吗？如果所有人物语气都跟作者一样——台词有问题。有魅力的人物说话方式跟常人不同，即使最平淡的事物也有独特说话方式。**让每句台词至少有一个词用独特方式强调，揭示人物前史/阴暗面/前程。**

### 转折要螺旋形上升
情节不能一直往前，必须**加快前进速度、加大复杂程度、然后达到高潮**。这是速度（等速）与加速度（速度增加）的区别。剧本有事件发生但无趣=只有追逐，他们到这里到那里，但没激起热情。

### 每部只用一种魔力
定律：每部影片请只使用一种魔力。检查是否违反。

### 原始吗（贯穿测试）
每个次要人物/次要情节都问：有原始驱动力吗？行为像正常人类吗？股票经纪人操纵国际债务市场→本质是"那家伙试图活下去"。把每个人愿望翻译到原始层次。

### 铺垫别超 25 页
设置部分超过 25 页还在说明 = 有问题，观众会喊退钱。

### 打破第四面墙
把媒体带进故事会在影片和观众间竖起第四面墙。检查是否不慎引入。

## 输出格式

```
# 故事诊断报告

## 主干5问
1-5 逐条：✅/⚠️/❌ + 问题
（任一答不出 → 主干没理直，先回去补，别逐拍了）

## 9条检查
1-9 逐条：✅/⚠️/❌ + 问题

## 逐拍诊断（15拍）
| 节拍 | 绿灯清单关键问 | 判定 | 问题 | 改写方向 |
|---|---|---|---|---|
| 开场画面 | 有风格？带进情绪？故事前快照？ | ⚠️ | …… | …… |
| 主题呈现 | 提及主题大前提？原始？ | ✅ | | |
| …| | | | |

## 专项检测
- 示而不讲：找到 ___ 处"说情节"，建议改画面：……
- 坏蛋强度：……
- 劣质台词：盖名测试结果：……
- 转折螺旋：中点后提速？……
- 原始性：每个次要人物驱动力：……
- 铺垫长度 / 魔力数量 / 第四面墙：……

## 改写优先级
1. 致命（主干级）：……
2. 重要（节拍级）：……
3. 润色（专项级）：……

按这个顺序改，先改致命的再改重要的，不要先润色。
```

## 注意

- 诊断必须落到具体哪一拍/哪一句，不要给"整体不够紧凑"这种空话。
- 改写方向要可执行——给"把这句台词改成什么动作"而不是"台词要更精炼"。
- 媒介换算见套件 README。
- 不脑补原书没有的检查项。专项检测只跑上面列的这些，不要自己加"节奏感""网感"这类非原书概念。
